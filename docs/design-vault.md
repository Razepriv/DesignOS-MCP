# Design Vault

Design Vault is the persistent knowledge layer behind DesignOS.

It stores things such as:
- reference metadata
- Design DNA
- approved directions
- rejected directions
- design systems
- research results
- visual fingerprints
- project knowledge

The Design Vault leverages an Obsidian-compatible persistent memory structure formatted as Markdown with YAML frontmatter. This enables seamless traversal by both humans and AI agents.
