# Design DNA

Design DNA is the structured output of understanding a visual reference.

Every reference analyzed by DesignOS normalizes into structured principles instead of raw DOM dumps. 
It captures:
- `style` and `emotionalTone`
- `composition`, `grid`, and `hierarchy`
- `typography`, `typeScale`, and `spacing`
- `palette` and `colorRatios`
- `motion`, `timing`, and `interactions`
- `responsiveBehavior` and `performanceObservations`

This allows AI coding agents to recreate the *feel* and *principles* of a reference using the user's specific brand and requirements, rather than cloning existing proprietary designs.
