# FAQ

**Is DesignOS a UI application?**
No. Core DesignOS is MCP + SDK infrastructure.

**Does DesignOS copy websites?**
No.

**Does it download premium components?**
Only when access and licensing permit it.

**Does it require a cloud service?**
Core should operate locally; some integrations require external APIs.

**Does it work without TinyFish?**
Yes, with fallbacks.

**Does it require Open Design?**
No. Open Design integration is optional.

**Can I add my own design source?**
Yes.

**Does it support private design systems?**
Yes.
