# DesignOS Clipper

The DesignOS Clipper is a browser extension and API interface that allows you to capture raw web resources directly into your Design Vault.

## Pipeline
`Browser` ↓ `DesignOS Clipper` ↓ `Asset Library` ↓ `Design DNA` ↓ `Embeddings` ↓ `Design Vault` ↓ `Research Engine` ↓ `Moodboard`

Captured elements retain full provenance and CSS structure while explicitly stripping executable scripts for security.
