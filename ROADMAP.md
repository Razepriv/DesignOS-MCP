# DesignOS Roadmap

The development of DesignOS is tracked across major versions based on core design capabilities.

### V0 — Foundation (Done)
- [x] Monorepo workspace initialization
- [x] Basic MCP contract definition
- [x] Initial design source registry setup
- [x] Local environment bootstrapping

### V1 — Core Design Intelligence (Stable / In Progress)
- [x] Database persistence (SQLite)
- [x] Exact Cache & Semantic Cache infrastructure
- [x] Caveman context compression
- [x] Token governor
- [x] Adaptive interview generation (engine)
- [x] Design DNA extraction structures
- [x] Core source routing and deep adapters (270+ sources)
- [ ] Complete Design Vault markdown syncing
